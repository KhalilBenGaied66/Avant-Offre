# Avant-Offre — working rules for Claude Code

Avant-Offre is a go/no-go copilot for a corporate bid office answering French public
tenders. It is a portfolio project for AI Engineer / Forward Deployed Engineer roles.
Reviewers will read the code, the decision log and the evaluation reports. Quality of
judgment matters as much as quality of code.

Always read `docs/SPEC.md` and `docs/DECISIONS.md` before starting a task.

## Non-negotiable rules
1. **AI only where it earns its place.** Follow the 8 decision rules in `docs/DECISIONS.md`.
   Any new use of an LLM, embeddings or a reranker needs a row in the decision log and a
   measured comparison against the simplest baseline.
2. **Every number shown to a user is computed in code (SQL/Python).** An LLM may phrase a
   number, never produce one. Briefs pass the numeric verifier (SPEC §6.9) or fall back to
   the deterministic template.
3. **Never invent data or results.** Do not guess column names: load the schema and print
   the columns before writing a transform. Do not write evaluation numbers by hand: reports
   are generated by `make eval*`. If a run cannot finish, say so and stop.
4. **No fake users.** The project has not been tested with real users. Never write user
   quotes, satisfaction scores or "validated with bid managers". The README says plainly
   that validation is against public award outcomes only.
5. **No leakage in evaluation.** Anything used to build a profile, a statistic or an index
   for the backtest must be dated strictly before the cutoff. Write a test for it.
6. **Personal data.** Some award winners are sole traders (natural persons). Never show their
   names in the demo, the UI or committed reports; use the pseudonymization rule in SPEC §4.6.
7. **Read-only towards the outside world.** No tool, agent or endpoint sends messages, submits
   bids or writes to external systems.

## Commands (keep this list current)
- Cloud sessions install deps automatically (`.claude/hooks/session-start.sh`).
- `make setup` install deps (uv) · `make lint` ruff + mypy · `make test` pytest ·
  `make lint-workflows` actionlint on CI files
- `make check-sources` reachability of every data source
- `make data-sample` / `make data-full` ingest + normalize · `uv run avant-offre data --no-download` rebuild from the snapshots on disk
- `make quality` regenerate `docs/DATA_QUALITY.md`
- `make index-sample` / `make index-full` BM25 + vectors
- `make eval-sample` / `make eval-full` all backtests → `reports/`
- `uv run avant-offre index [--dense]` · `match --siret <s>` · `intel --notice <id>` ·
  `score --notice <id> --siret <s>` · `brief --notice <id> --siret <s>` · `extract`
- single backtests: `uv run avant-offre eval matching-baselines|matching|embed|competitors|prices|briefs|summary`
- `make serve` FastAPI on :8000 · `make mcp` MCP server (stdio; `make mcp-http` for HTTP) ·
  `make web-install web` React review page on :5173 · `uv run avant-offre digest --siret <s>`
- `make llm-local` free local LLM endpoint on :8080 (llama.cpp, open-weights model; first run
  builds and downloads) · `uv run avant-offre briefs --siret <s>` weekly batch: cache the
  week's briefs
- `uv run avant-offre demo-export --siret <s> --out demo/` · `demo-load demo/` pseudonymized snapshot

## Conventions
- Python 3.12, uv, type hints everywhere, ruff, mypy (strict on `src/`), pytest.
- Config in `config/*.yaml`, loaded once through `avant_offre.settings` (pydantic-settings).
  No hard-coded paths, dates, thresholds or model names in modules.
- DuckDB is the single relational store (`data/avant_offre.duckdb`). Parquet for raw and
  processed snapshots. LanceDB for vectors (`data/vectors/`).
- Every data snapshot records its download date and source URL in `data/manifest.json`.
- Seeds fixed in config; every report prints config hash, snapshot date, git commit.
- LLM calls only through `avant_offre.llm.gateway` (LiteLLM). Each call is traced to
  `data/traces/*.jsonl` (model, prompt hash, tokens, latency, cost estimate, verifier result).
- Sample mode (`AVANT_OFFRE_MODE=sample`) must make every command run on a small VM.
- Commit per milestone step with clear messages; run `make lint test` before committing.
- Approved dependencies: duckdb, polars, pyarrow, httpx, tenacity, pydantic, pydantic-settings,
  pyyaml, typer, rich, rapidfuzz, lancedb, sentence-transformers, torch (CPU), bm25s,
  litellm, jinja2, fastapi, uvicorn, mcp, numpy, scipy, matplotlib, pytest, ruff, mypy.
  Ask before adding anything else.

## When unsure
Stop and write the question in your report rather than guessing. Ambiguity in the data
(odd fields, missing values, surprising distributions) is a finding: record it in
`docs/DATA_QUALITY.md`.
